# Reglas funcionales transversales

- Este repositorio promociona soluciones AlmaSoft; no ejecuta operaciones crediticias, contables ni de cooperativas. Las capacidades comerciales no prueban implementación de esos sistemas en este código.
- No inventar módulos, cumplimiento regulatorio, cálculos, integraciones o capacidades de envío. La autorización del usuario define el alcance del contenido.
- Microfinanzas y Cooperativas tienen contenido independiente; no transferir automáticamente requisitos CONAMI, PRIM, MUC o PLA a Cooperativas.
- «Solicitar demostración» lleva a contacto; no equivale a una reserva o solicitud enviada.
- Datos de contacto no configurados no deben convertirse en enlaces ficticios ni reemplazarse por datos inventados.

Reglas específicas, sin duplicarlas aquí: [módulos de producto](modules/SOLUTIONS.md), [NO/SÍ del robot](modules/ROBOT_CTA.md), [envío del formulario](modules/CONTACT.md).
